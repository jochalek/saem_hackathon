#+title: SAEM Hackathon
* Objectives
1. Categorize patients at triage by what drug they most likely took
2. Predict disposition ("Dischage", "Floor", "ICU") based on the first 4-hours of ED visit. ONLY predict for patients categorized as having taken a novel party drug
3. Make an app (or paper printout) to help triage patients

* Symptom constellation pseudo-label pipeline
- Script: ~scripts/discover_pseudo_labels_symptom_constellation.py~
- Uses local ClinicalBERT (~emilyalsentzer/Bio_ClinicalBERT~) + rule-based symptom triple extraction + toxidrome prototype matching + residual clustering.
- Create token file: ~cp .env.example .env~ then set ~HF_TOKEN=...~
- Run: ~uv run python scripts/discover_pseudo_labels_symptom_constellation.py~
- Output: ~outputs/pseudo_labels_symptom_constellation/~
